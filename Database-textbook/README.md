# Database Textbook

This folder contains the concept-focused part of the course. Start with the fundamentals, then move into SQL, views and constraints, and finally PL/SQL.

| Lesson | What you will learn |
|---|---|
| [Database.md](Database.md) | DBMS purpose, database users, SQL command families, and transactions |
| [Connection.md](Connection.md) | Connecting with SQL\*Plus and working through DDL, DML, joins, filtering, and functions |
| [syntax.md](syntax.md) | A compact Oracle SQL and PL/SQL reference |
| [VIEW.md](VIEW.md) | Views, updatable views, `CHECK` constraints, composite primary keys, and CTAS |
| [interview.md](interview.md) | 25 common DBMS/SQL/PLSQL questions with concise answers |
| [PLSQL/README.md](PLSQL/README.md) | PL/SQL lesson index and runnable programs |

## Recommended order

```text
Database fundamentals
        ↓
SQL*Plus workbook ──→ SQL quick reference
        ↓
Views and constraints
        ↓
PL/SQL fundamentals ──→ Worked programs
        ↓
Interview review
```

The adjacent `.txt` files are the original classroom notes. Use the Markdown files for learning and the text files only when you want to compare with the historical transcript.
