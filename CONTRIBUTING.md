# Contributing

Thank you for helping improve these Oracle SQL and PL/SQL learning resources.

## Good contributions

- correct technical or language errors;
- improve explanations without removing useful history;
- add safe, focused examples and expected output;
- answer an unanswered learning question;
- improve accessibility, navigation, or formatting; and
- report version-specific behavior clearly.

## Before submitting

1. Search existing issues and pull requests.
2. Use a focused branch and keep the change small enough to review.
3. Test SQL or PL/SQL in an authorized disposable Oracle schema when possible.
4. Explain the Oracle version and tool used for version-sensitive behavior.
5. Preserve the original `.txt` archives unless a rights, privacy, or safety concern requires review.
6. Do not include secrets, private data, copied proprietary training material, or content you cannot license.

## Licensing of contributions

By intentionally submitting a contribution, you represent that you have the right to submit it and agree that it may be distributed under **CC BY-NC-SA 4.0**, the repository’s existing license, unless a separate written agreement is made before submission.

Do not submit third-party material unless its license is compatible and you provide all required attribution and notices. Clearly identify any material not covered by the repository license.

The maintainer may edit, decline, or request changes to a contribution. Submission does not guarantee acceptance.

## Style

- Use clear beginner-friendly English.
- Use uppercase SQL keywords and meaningful identifiers.
- Prefer named constraints and explicit column lists.
- Explain destructive commands and transaction boundaries.
- Use fenced code blocks with `sql`, `console`, or `text` language tags.
- Add relative links and verify they resolve.
- Distinguish historical transcript behavior from corrected recommendations.

## Conduct and security

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report sensitive vulnerabilities privately according to [SECURITY.md](SECURITY.md), not in a public issue.
